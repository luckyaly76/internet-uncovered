03 - TRANSPORT PROTOCOLS

TCP vs UDP: What's the difference?

TCP and UDP are two transport protocols. They both carry data between devices, but they work differently.

TCP

Reliable delivery

TCP checks that data arrives correctly and in the right order. If something is missing, it can be sent again.

Common uses: Web browsing, email and file transfers.

UDP

Faster, connectionless delivery

UDP sends data without checking that every part arrives. This can make communication faster.

Common uses: Live streaming, online games and voice calls.

04 - WEB SECURITY

HTTPS & TLS: How secure connections work

HTTPS protects communication between your browser and a website. It uses TLS to help keep information private and secure.

HTTP

Unencrypted communication

HTTP transfers information without encryption. This means the data is not protected by HTTPS security.

Default port: 80

HTTPS

Encrypted communication

HTTPS uses TLS to encrypt communication, helping protect information exchanged between your browser and the website.

Default port: 443

What does TLS do?

TLS helps establish a secure connection, authenticates the website using digital certificates, and protects data through encryption while it travels across the network.
