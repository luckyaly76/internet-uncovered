# Protocol Explorer — Lucky Ali Edition

A small, original, beginner-friendly networking learning website.

## Run it
1. Extract the ZIP file.
2. Open the `lucky_ali_protocol_explorer` folder in Visual Studio Code.
3. Open `index.html`.
4. If you have the VS Code Live Server extension installed, right-click `index.html` and choose **Open with Live Server**. Otherwise, double-click `index.html` in File Explorer to open it in your browser.

No build tools, paid accounts, or server are required.

## Customise your credit
Search in `index.html` for `Lucky Ali` and replace it with the name you want.

## Files
- `index.html` — page structure and content
- `styles.css` — colours, layout, and responsive design
- `script.js` — interactive protocol cards, request walkthrough, and quiz

## About this project
This is an independently created educational demo inspired by the general idea of interactive networking education. It is not the original Protocol Explorer project and does not include its source code or assets.
